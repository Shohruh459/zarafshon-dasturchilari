# 10-video: Git nima? (o'zgarishlar tarixi) — SSENARIY (tasdiq kutilmoqda)

Yuklash sanasi: **12.10.2026** (keyingi: 11-video 13.10).
Uslub: CSS + Blender noutbuk (9-video kabi), metaforasiz aniq tushuntirish, yangi hook formulasi ("Kelishganimizdek, bugun siz bilan X ni o'rganamiz"), "kim uchun" yozuvisiz. ~42–45 s, 1080x1920, 30 fps.
Bitta g'oya: Git = dastur fayllaridagi o'zgarishlar tarixini saqlaydi; xohlagan saqlash nuqtasiga qaytish mumkin.

## 1. HOOK (0–9 s) — kinetik
0-kadrdan katta: "KELISHGANIMIZDEK / BUGUN SIZ BILAN **GIT** NIMALIGINI O‘RGANAMIZ". Keyin Blender noutbuk ekranida fayl ro'yxati: sayt.html, sayt_yangi.html, sayt_yangi2.html, sayt_OXIRGI.html, sayt_OXIRGI_haqiqiy.html (namuna).
- Ovoz: "Kelishganimizdek, bugun siz bilan Git nimaligini o'rganamiz. Fayl nomiga oxirgi, haqiqiy oxirgi deb yozganmisiz? Git shu muammoni hal qiladi. Oxirigacha qoling!"
- Foydalar: "✔ Git nima ekanini bilasiz" | "✔ Eski nusxaga qanday qaytishni tushunasiz" | "Oxirigacha qoling 👇"

## 2. MUAMMO (9–16 s)
Fayl ro'yxati kattalashadi, fayllar ko'payadi, "qaysi biri to'g'ri?" belgisi.
- "Har o'zgarishda yangi nusxa yaratasiz."
- "Fayllar ko'payadi, qaysi biri to'g'ri ekanini unutasiz."

## 3. GIT NIMA (16–27 s)
Vaqt chizig'i: saqlash nuqtalari paydo bo'ladi (xabarlari namuna: "birinchi sahifa", "tugma qo'shildi", "rang o'zgardi"). Eski nuqtaga qaytish animatsiyasi.
- "Git dasturdagi o'zgarishlar tarixini saqlaydi."
- "Har saqlash nuqtasi, commit deyiladi." (izoh: "commit, o'zgarishlarni xabar bilan saqlash")
- "Xohlagan nuqtaga qaytishingiz mumkin."

## 4. BUYRUQLAR (27–36 s) — terminal (haqiqiy buyruqlar, chiqish NAMUNA)
`git init` (loyihada bir marta) → `git add .` → `git commit -m "tugma qo'shildi"` → `git log` (tarix ro'yxati).
- "Boshida bir marta git init yozasiz."
- "Saqlash uchun: git add va git commit."
- "Tarixni git log ko'rsatadi."
(chiqish soxta: commit raqamlari qisqartirilgan, muallif "Ali", "namuna chiqish" belgisi)

## 5. XULOSA + CTA (36–44 s)
- "Xulosa: Git, o'zgarishlar tarixini saqlaydi."
- "Saqlab qo'ying. Keyingi videoda: GitHub, ya'ni kodingizni internetda saqlash!"
- Ekranda 9 qatorli xulosa (… Docker ✓ Git ✓); prompt: "Git nima? Commit nimaligini oddiy tushuntir va git log nima qilishini ayt."

## Halollik
Git va GitHub bir narsa emas (GitHub keyingi videoda). Narx/shartlar tilga olinmaydi. Saqlash nuqtasini o'zingiz yaratasiz (avtomatik emas), shu aytiladi. Natija kafolati yo'q.
