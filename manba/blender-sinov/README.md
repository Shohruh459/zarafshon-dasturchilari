# Blender (Cycles) sinovi

- O'rnatish: `pip install bpy` (≈ 20 s, Blender 5.0 Python moduli). Ishga tushirish: `python3 bl_test.py <namuna> <o'lcham_koeffitsiyent> <chiqish.png>`
- Muhit: 4 yadroli CPU, GPU yo'q. Cycles (CPU) ishlaydi; EEVEE ishlamaydi (libEGL yo'q).
- Natija: 1080x1920, 48 namuna + denoise ≈ 30 s/kadr; 540x960, 24 namuna ≈ 5 s/kadr.
- `screen.png` — `manba` ichidagi sayt namunasi skrinshoti bilan almashtiriladi.
