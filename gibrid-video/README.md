# Gibrid video (WebGL 3D + CSS qatlam)

- 3D qismi: `three.js` (telefon, yorug'lik, bloom, 3D konfetti, uchib keluvchi bloklar, 3D yorliqlar)
- Ustki qatlam: CSS/HTML (sarlavha, prompt kartalari, kursor, ostyozuv, qadam kartalari)
- Telefon ekrani: `tex0..3.png` (sayt holatlari: qizil, ko'k, katta tugma, yangi sarlavha), ular orasidagi o'tish shader orqali
- Render: `npm i three@0.160.0`, `python3 -m http.server 8766`, `python3 render6.py out.mp4` (≈14 daqiqa, 1080×1920)
